# dip2026

## 通用视频运动目标跟踪实验

固定机位下跟踪运动区域，不限制物体类别，支持视频和摄像头。不具备语义识别能力，显示的数量是分割区域数量。

## 安装运行
优先使用已有的dip环境。在本文件夹打开终端：
```powershell
conda activate dip
# 已有环境装有OpenCV和NumPy，不需要重新安装
python main.py --make-demo
python main.py --source "data/demo.avi" --save
python main.py --source 0
```
首帧作为初始参考背景；连续约两秒保持稳定的位置自动更新为背景，清除开头目标离开后的残影。建议首帧没有运动目标。摄像头启动时先保持场景为空，再让目标进入。B键将当前帧重设为背景并清空轨迹；空格暂停，任意键继续；Q或Esc退出。请在OpenCV窗口获得焦点后操作。

九个独立窗口按3×3排列，依次展示原图、亮度校正、高斯滤波、锐化、背景差分、二值分割、开运算、闭运算、跟踪结果。可手动移动和调整窗口大小。

## 默认设置
程序预设一套处理参数，无需手动设置：彩色图像各通道增亮20、高斯核5×5、开启锐化、差分阈值25、最小面积400、匹配距离80、处理宽度800。
原图、亮度校正、高斯滤波、锐化和跟踪结果均为彩色；锐化后转灰度用于背景差分，分割与形态学窗口为灰度或二值图。

运行选项仅保留 `--source`（默认摄像头0）、`--make-demo`（生成演示视频）、`--save`（保存视频与CSV，覆盖同名输出）、`--headless`（无窗口验证）。

固定机位、背景较稳定时效果较好。全局光照变化、阴影、物体遮挡会影响检测；多个区域合并或拆分会导致ID变化。首帧已有物体时，离开后原位置可能短暂出现残影，稳定约两秒后自动清除。真实目标停住约两秒也会被吸收为背景；像素噪声可能延长更新时间。亮度加减用于演示像素运算，不保证提升差分效果，过度增亮导致饱和反而会丢失细节。

全部代码合并在main.py，按注释分区组织预处理、分割与表示、质心跟踪、多窗口显示、演示生成和主流程。任务保持通用运动目标跟踪，不进行颜色筛选。
