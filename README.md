# dip2026

## 通用视频运动目标跟踪实验

固定机位下跟踪运动区域，不限制物体类别，支持视频和摄像头。不具备语义识别能力，显示的数量是分割区域数量。

## 安装运行
优先使用已有的dip环境。在本文件夹打开终端：
```powershell
conda activate dip
# 已有环境装有OpenCV和NumPy，不需要重新安装
python main.py --make-demo
python main.py --source "data/demo.avi" --save
python main.py --source 0
```
首帧作为固定参考背景，建议首帧没有运动目标。摄像头启动时先保持场景为空，再让目标进入。B键将当前帧重设为背景并清空轨迹；空格暂停，任意键继续；Q或Esc退出。请在OpenCV窗口获得焦点后操作。

九个独立窗口按3×3排列，依次展示原图、亮度校正、高斯滤波、锐化、背景差分、二值分割、开运算、闭运算、跟踪结果。可手动移动和调整窗口大小。

## 参数
- `--brightness 20`：固定亮度加减，范围-255到255；设0关闭。
- `--threshold 25`：差分阈值；噪点多时增大，漏检时减小。
- `--min-area 400`：最小轮廓面积；过滤较小区域。
- `--max-distance 80`：相邻帧允许的最大质心距离。
- `--width 800`：处理宽度，面积与距离参数对应此分辨率。
- `--no-sharpen`：关闭锐化用于对比。
- `--save`：保存output/tracking.avi及tracks.csv，每次运行覆盖同名输出。
- `--headless`：不打开窗口，适合批处理验证。

固定机位、背景较稳定时效果较好。全局光照变化、阴影、物体遮挡会影响检测；多个区域合并或拆分会导致ID变化。首帧已有物体时，该物体离开可能出现残留区域。物体停止后仍与固定背景不同，会继续被检测；本实验检测的是背景变化，不是严格的瞬时运动。亮度加减用于演示像素运算，不保证提升差分效果，过度增亮导致饱和反而会丢失细节。

全部代码合并在main.py，按注释分区组织预处理、分割与表示、质心跟踪、多窗口显示、演示生成和主流程。任务保持通用运动目标跟踪，不进行颜色筛选。
